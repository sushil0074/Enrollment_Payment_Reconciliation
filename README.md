# Enrollment-Payment Reconciliation (Excel)

Compares an enrollment list with payment records and shows who has paid, who owes money and where the data has mistakes.

**What it shows**
- Clean Key (UPPER and TRIM) so IDs typed as "s102" or "S103 " still match
- Paid and Balance per enrollment using SUMIF, and a status: PAID, PARTIAL, OVERPAID or UNPAID
- Data checks: duplicate enrollment rows, missing names, payments with no enrollment
- Summary sheet with counts, money totals and a check cell

The sample data contains planted mistakes so you can see each check work. All data is fictional.
